# Content Submission & Distribution Guide

This document maps the project deliverables to the official content submission requirements.

## 1. Technical Article Requirements
- Word count strictly between 800 and 1,500 words.
- Zero references to hackathons, competitions, or judging.
- Must include code snippets taken directly from the codebase.
- Must include Before vs. After contrast (Memory OFF vs. Memory ON).
- Must include links to Hindsight GitHub, Hindsight Docs, and Vectorize Agent Memory.
- Primary file: `content/articles/article.md`.

## 2. Social Post Requirements
- Total characters strictly under 800.
- No mention of hackathons.
- Project GitHub link in the body.
- Exactly 3 to 5 hashtags on the last line.
- Primary file: `content/social/linkedin-post.md`.

## 3. Video Requirements
- 2 to 5 minutes duration, 1080p recording.
- Clearly shows problem, memory off, memory on, live ingestion, and updated reflection.
- 16:9 thumbnail attached.
- Script and cues: `content/video/video-script.md` and `content/video/screen-cues.md`.
