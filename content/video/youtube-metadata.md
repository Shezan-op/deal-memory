## Description

Most enterprise sales AI tools treat calls as isolated summarization tasks. If offering a discount stalled your deal two weeks ago, a stateless LLM will still tell you to offer another discount today because it has zero concept of outcomes.

DealMemory solves this by creating an evidence-based learning loop:
1. Interaction (Rep attempts action)
2. Retain (Deterministic ingestion into Hindsight)
3. Outcome Observed (Deal progressed, stalled, or lost)
4. Retain Outcome (Linked directly to interaction document ID)
5. Consolidation (Hindsight forms observed patterns & mental models)
6. Future Action (Better, evidence-grounded recommendations)

In this 2-minute walkthrough, we show:
- Memory OFF vs. Memory ON contrast on an active enterprise deal (Acme Corp).
- How Hindsight flags a discount failure and recommends an engineering migration plan.
- How DealMemory detects contradictory budget signals across stakeholders ($100k vs $85k).
- Live outcome retention into a Hindsight memory bank.
