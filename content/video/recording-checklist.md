# Video Recording Checklist

## Environment Preparation
- [ ] Screen resolution set to 1920x1080 (1080p) or 2560x1440 (1440p).
- [ ] Browser window zoomed to 110%–125% for high readability on mobile devices.
- [ ] Dev server running cleanly on `http://localhost:3000` with seed data loaded (`npm run seed`).
- [ ] Close all extraneous browser tabs, bookmarks bars, and desktop notification popups.
- [ ] Microphone gain checked; zero background echo or hum.

## Take Execution
- [ ] Speak naturally and conversationally without rushing.
- [ ] Keep mouse movements slow, deliberate, and smooth.
- [ ] Pause 1 second before and after clicking navigation items to allow viewers to process UI updates.
- [ ] Verify total length lands between 2:00 and 3:00 minutes.
