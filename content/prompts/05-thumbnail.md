# Thumbnail Design Prompt

Instructions for designing a 16:9 YouTube video thumbnail.

## Visual Requirements
- Aspect Ratio: 16:9 (1920x1080px).
- Palette: Warm bone / off-white background (`#f7f6f0`), dark ink text (`#181817`), deep emerald green accent (`#1e3a1e`).
- Typography: Bold serif headline, technical monospaced badge.
- Main Text: "Sales AI That Learns from Outcomes"
- Secondary Sub-badge: "Powered by Hindsight Engine"
- Visual Elements: Clean side-by-side terminal / card contrast showing:
  - Left: "Generic Prompt: Offer 15% discount (Stalled)"
  - Right: "Hindsight Memory: Migration Roadmap (Won Acceptance)"
- Composition: Ample whitespace, high contrast, legible even at mobile avatar thumbnail scales.
