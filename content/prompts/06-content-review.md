# Content Review & Validation Prompt

Review criteria applied to all generated deliverables prior to public release.

## Article Rules
- [ ] Word count is between 800 and 1,500 words.
- [ ] Zero instances of the word "hackathon", "competition", "contest", or "judges".
- [ ] Direct, first-person developer tone.
- [ ] Contains actual code blocks matching files in `src/`.
- [ ] Contains links to Hindsight GitHub, Hindsight Docs, and Vectorize Agent Memory.

## Social Post Rules
- [ ] Total character count strictly under 800 characters.
- [ ] No mention of hackathons or student projects.
- [ ] Opening hook contains no links or hashtags.
- [ ] Exactly 3–5 relevant hashtags on the final line only.
- [ ] Includes project GitHub link in main body.

## Video Rules
- [ ] Length between 2 and 5 minutes.
- [ ] Resolution 1080p minimum.
- [ ] Clear demonstration of Problem → Memory OFF → Memory ON → Ingestion → Learning.
