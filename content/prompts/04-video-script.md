# Video Script Generation Prompt

Instructions for producing a high-impact, 2–3 minute walkthrough video script.

## Structure
1. **0:00 - 0:25: Problem Formulation**
   - The failure of traditional sales AI: endless conversation summaries that never change future behavior.
   - Introduce DealMemory: an agent that retains actions, logs their outcomes, and learns.
2. **0:25 - 0:55: The Contrast (Memory OFF vs. Memory ON)**
   - Open Acme Corp deal.
   - Run preparation with Memory OFF: generic advice to give a 15% discount.
   - Flip Memory ON: agent warns against discounting because Interaction #002 stalled after a discount; instead recommends a migration roadmap.
3. **0:55 - 1:40: Traceable Evidence & Ingestion**
   - Open evidence drawer: trace the recommendation to deterministic document IDs in Hindsight.
   - Log a live interaction outcome: Sarah Jenkins accepts the migration timeline and David Park approves SOC2.
   - Ingest into Hindsight.
4. **1:40 - 2:30: Consolidated Mental Model & Next Steps**
   - Show updated reflection: agent synthesizes the progression milestone.
   - Highlight the feedback loop: Action → Outcome → Consolidated Strategy.
