# Social Post Generation Prompt

Instructions for drafting developer social posts (LinkedIn / X) for DealMemory.

## Guidelines
1. Length: strictly under 800 characters.
2. Hook: high-signal engineering problem in the opening 2 lines (no links or hashtags in the hook).
3. Core thesis: explain why sales AI fails when it only summarizes rather than remembering what actions succeeded or stalled.
4. Name Hindsight as the memory foundation.
5. Provide the project GitHub repository link in the body.
6. Absolutely no mention of hackathons, contests, or student projects.
7. Last line only: exactly 3 to 5 relevant hashtags (#AgenticAI, #SoftwareEngineering, #LLMs, #SystemDesign).
