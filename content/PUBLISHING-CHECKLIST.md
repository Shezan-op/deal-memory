# Publishing Checklist

Complete this checklist prior to public release.

## 1. Technical Article Checklist

- [ ] Word count verified within 800–1,500 words using `npm run content:check`.
- [ ] Absolutely no mentions of hackathon, competition, judging, or prizes in title or body.
- [ ] High-contrast, authentic engineering title focusing on technical architecture or learning.
- [ ] Contains 2–4 actual, verified code snippets from the repository.
- [ ] Includes clear Before vs. After contrast (Memory OFF vs. Memory ON).
- [ ] Explains Hindsight retention, recall, and reflection mechanics accurately.
- [ ] Discusses an honest limitation, dead end, or engineering trade-off.
- [ ] Contains working markdown links to:
  - Hindsight GitHub: https://github.com/vectorize-io/hindsight
  - Hindsight Documentation: https://hindsight.vectorize.io/
  - Vectorize Agent Memory: https://vectorize.io/what-is-agent-memory

## 2. Social Post Checklist (LinkedIn / X)

- [ ] Character count strictly under 800 characters.
- [ ] No mention of hackathons, challenges, or student framing.
- [ ] High-signal opening hook without external links.
- [ ] Focuses on the core technical insight: Action → Outcome → Consolidated Memory.
- [ ] Includes GitHub repository link in the primary post body.
- [ ] Exactly 3–5 relevant hashtags on the final line only.
- [ ] Article URL prepared to post as the first comment upon publication.
- [ ] Hindsight GitHub link prepared to post as a secondary comment.

## 3. Video Checklist

- [ ] Duration between 2 and 5 minutes.
- [ ] Screen recording captured in 1080p minimum.
- [ ] Demonstrates Problem → Memory OFF → Memory ON → Outcome Logging → Updated Learning.
- [ ] Audio clean, crisp, and conversational.
- [ ] 16:9 thumbnail attached.
- [ ] Description populated using `content/video/youtube-metadata.md`.

## 4. Reddit Checklist (Optional Link Post)

- [ ] Target subreddit selected: r/llmdevs, r/sideproject, r/aiagents, or r/aimemory.
- [ ] Title describes the technical implementation or lesson learned.
- [ ] Direct link to the published technical article.
- [ ] No self-promotional spam; actively engage with comments on memory architectures.
