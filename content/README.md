# Content Submission Workspace

This workspace organizes the required deliverables for project submission and technical publication.

## Directory Structure

- `articles/`: Technical developer articles (800–1,500 words, no forbidden terms, markdown format).
- `social/`: Developer-focused social posts (<800 characters, no forbidden terms, relevant hashtags on last line).
- `video/`: Demo video scripts, screen cues, and YouTube submission metadata.
- `thumbnails/`: 16:9 thumbnail concepts and specifications.
- `screenshots/`: Real application screenshots and before/after comparisons.
- `diagrams/`: High-resolution architectural and learning loop diagrams.
- `prompts/`: Standardized, reproducible prompts for generating deliverables from repository code.
- `final/`: Staged assets verified and ready for distribution.

## Guidelines

- All articles and social posts must be developer-oriented and linkable.
- Never include forbidden references to hackathons or competitions in article titles, bodies, or social posts.
- Maintain an authentic, first-person engineering voice.
- Ensure all code snippets in articles match actual files in this repository.
- Verify deliverables with `npm run content:check` before publication.
